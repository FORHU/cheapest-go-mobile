# Mock catalogue photos

Photos for the mock hotels, rooms, golf courses and destinations, bundled so the
app works offline. All come from [Unsplash](https://unsplash.com) under the
[Unsplash License](https://unsplash.com/license) (free to use, no attribution
required), resized to 800 × 560.

They illustrate invented hotels and courses only. None shows the real property
it is attached to in the app, so replace them with supplier photos once the
catalogue comes from `cheapestgo-api-v2`.

| Folder | Count | What |
|---|---|---|
| `hotels/` | 24 | Hotel exteriors, pools, resorts (card covers) |
| `rooms/` | 11 | Bedrooms, suites, lobbies (gallery) |
| `golf/` | 16 | Courses, greens, golfers |
| `places/` | 10 | One per arrival airport, named by IATA code |
